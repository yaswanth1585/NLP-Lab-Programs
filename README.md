# NLP Lab Programs

Ten Jupyter notebooks for Natural Language Processing labs. The filenames follow the LAB-1.ipynb to LAB-10.ipynb format.

## How to use
1. Open a notebook in GitHub to view the code.
2. To run the notebook, download it and open it in Jupyter Notebook, JupyterLab, or Google Colab.
3. Some programs require installing libraries such as nltk, scikit-learn, gensim, tensorflow, pandas, matplotlib, and wordcloud.

## Lab list
1. Text Cleaning
2. NLP Preprocessing
3. One-Hot Encoding, Bag of Words and Word Cloud
4. TF-IDF
5. Naive Bayes and SVM
6. News Classification
7. Word2Vec
8. GloVe Word Embeddings
9. LSTM
10. Sentiment Analysis using LSTM
