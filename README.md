# NLP Lab Programs

This repository contains In-Lab and Post-Lab programs for Natural Language Processing using Python.

## Topics Covered
1. Text Cleaning
2. NLP Preprocessing
3. One-Hot Encoding, Bag of Words and Word Cloud
4. TF-IDF
5. Naive Bayes Spam Detection and SVM Sentiment Analysis
6. News Article Classification
7. Word2Vec
8. GloVe
9. LSTM Sentiment Analysis

## Technologies Used
- Python
- NLTK
- Scikit-learn
- Gensim
- TensorFlow
- Pandas
- Matplotlib
- WordCloud
